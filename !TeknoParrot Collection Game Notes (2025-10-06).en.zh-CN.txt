iDmacDrv32.dll

某些游戏的档案中会有旧版本的 iDmacDrv32.dll，这可能比 TPUI 建议使用的当前版本更旧。

如果您在游戏根文件夹中包含 iDmacDrv32.dll 时遇到任何问题，请重命名该 dll 文件并启动游戏。TPUI 会自动将当前的 iDmacDrv32.dll 从其存储库复制到游戏文件夹并使用它。如果问题得到解决，请继续使用新的 iDmacDrv32.dll

如何在不使用 TPUI 的情况下直接运行游戏

D:\TeknoParrot\TeknoParrotUi.exe --profile=GoldenTeeLive2012.xml

您需要确保已预先设置好游戏的所有设置，包括游戏可执行文件的路径。

您可以从 TeknoParrot\GameProfiles 文件夹中获取配置文件名称，或者通过在此文档中搜索游戏来获取配置文件名称，配置文件名称将显示在游戏标题旁边的括号中。

SEGA LINDBERGH、SEGA ALLS SRAM 和 EEPROM 保存位置：

%USERPROFILE%\AppData\Roaming\TeknoParrot

每个游戏都会有以下格式的文件：
XXXX_sram.bin
XXXX_e2prom.bin

============================================
NESiCAxLive 游戏文件

如果您查看 NESiCA 游戏文件夹的根目录并看到以下 .dds 文件，请不要管它们。
NxLCountDownRenderer_HD.dds（2048x512）
NxLCountDownRenderer_HD_V.dds（512x1024）
NxLCountDownRenderer_SD.dds（1024x256）
NxLCountDownRenderer_SD_V.dds（256x512）

它们属于游戏本身，并非像某些用户所言，是由第三方工具添加的。它们是游戏加载程序创建并用于在游戏启动时进行倒计时的图形图块。遗憾的是，该过程被 TPUI 屏蔽了，所以你实际上看不到它们。它们支持标清和高清分辨率，适用于竖屏和横屏。

如果删除这些 .dds 文件，这并不是世界末日，但是，如果这些文件丢失，游戏将不再加载游戏内边框（如果有）。

RPCS3 首次启动需要 2-4 分钟来创建缓存/着色器文件，这些文件存储在 RPCS3\cache 文件夹中。创建完成后，后续游戏启动速度将显著加快。

Windows 缩放
将 Windows 缩放比例设置为 100%，否则在十字准线游戏中您的目标将会偏离。

============================================
全屏分辨率
部分游戏在全屏模式下运行可能会受到高于 60Hz 的显示器频率影响。请将频率降至 60Hz 以解决此问题。（例如《星际迷航》、《HOTD4》、《黄金枪》、《变形金刚》）

BepInEx Unity 游戏
首次启动包含 BepInEx 文件夹的 Unity 游戏时，请允许游戏启动，然后退出并重新启动游戏。这将允许 BepInEx 保存并更新其插件配置。之后，该插件将完全配置。

- 在游戏设置下，启用分数提交，您可以选择现在启用 GUI，以便在屏幕上呈现 GUI 以及游戏信息等

太辣（2Spicy）

exe:\elf\apacheM.elf
- 全屏：1280x768显示分辨率
- 窗口：1280x768 窗口分辨率
- 全屏窗口：1280x768 显示分辨率
**这是游戏的原始分辨率**

如果您使用的是 AMD GPU，请在游戏的 TPUI 设置中启用 AMD 修复，并从 TP Discord（#fixes 频道）获取修复

其他精灵的：
apacheM_HD.elf
- 与 apacheM.elf 相同的 CRC，因此它毫无用处，因为它会做与 apacheM.elf 相同的事情

apacheM_VGA.elf - 此 elf 中只有一个字节与 apacheM.elf 不同
- 全屏：显示分辨率为 1280x768。不是 VGA。
- 窗口模式：窗口分辨率为 1280x768。仍然不是 VGA。
- 全屏窗口：显示分辨率为 1280x768。完全不是 VGA。

apachetestM.elf
- 这是唯一有效的测试模式精灵，并且游戏必须设置为 EXPORT 区域。
- 服务菜单中的任何更改都不会保存，所以目前毫无用处。TP 开发人员似乎尚未实现服务菜单的更改。这有点糟糕，因为难度和剧情都可以更改。

apachetestM_HD.elf
- 与 apachetestM.elf 相同

apachetestM_VGA.elf
- 在任何区域设置下均不起作用

3D角色扮演麻将（3DCosplayMahjong）

- 游戏仅在窗口模式下运行
- 如果您尝试以全屏方式运行它，您将遇到以下错误：
错误！！：Create3DDevice
fGf%.!! ：游戏

我遇到的唯一强制游戏全屏运行的解决方法是使用 GitHub 上的“无边框游戏”（BG）（https://github.com/Codeusa/Borderless-Gaming/releases）。这是一个安全的应用程序，你可以将它应用于正在运行的应用程序，这些应用程序会将其窗口扩展到全屏，并根据你显示器的分辨率进行调整。  

我已经用这款游戏测试了 BG，效果很好。下载最新的非 Steam 版本，安装并运行 BG 应用。正常运行 TeknoParrot，选择“3D Cosplay”游戏，并确保将其设置为“窗口化”模式。运行游戏。游戏启动后，在 BG 窗口中的应用程序列表中找到名为“3DCustomMahjong [Title]”的应用程序。选中它，然后点击向右箭头将其移动到“收藏夹（自动）”列表中。现在，无论何时运行 BG，然后运行“3D Cosplay”，BG 都会自动将游戏切换到全屏模式。

也许 TP 开发人员可以解决这个问题，但可能不行，因为他们根本不在乎麻将游戏，即使有挑逗性的女士用他们的好东西调情。

奇怪的是，这款游戏似乎有两种视频模式：水平和垂直（基于 movie_h.wmv 和 movie_v.wmv 游戏文件）。然而，查看服务菜单后，却发现无法更改屏幕方向。

Akuma Mortis 不朽（Akuma）

这款游戏不支持第 12 代到第 14 代英特尔 CPU（不是 GPU，我说的是 CPU）。你可以完美设置所有东西，但扳机键就是无法工作。就算你尝试将它们映射到控制器或键盘上，扳机键也根本无法工作。我只能亲自确认第 13 代酷睿 i7 无法工作，其他报告来自其他用户。

我已经使用 TPUI 进行了测试，确认游戏在第 11 代英特尔 CPU 上完全可以运行。游戏应该也能在老一代 CPU 上运行。

游戏设置：
- 在 Game.exe 上，将兼容模式设置为 Windows XP SP3
- 以管理员身份运行此游戏的 TPUI（以使兼容模式正常工作）
- 使用 RawInput、HideCursor、FpsLimitEnable (60)、Crosshair Enable、Bezel Enable 设置游戏。
- 将光枪映射到鼠标上。  
- 玩游戏。

“expdat”和“extdat”文件是启用了“自由游戏”的 NVRAM 的补丁版本（这样您就知道您正在使用补丁文件）。尝试使用这两个文件的“原始”版本将导致所有输入功能都无法正常工作，并且游戏将不再处于“自由游戏”模式。当 TPUI 中的任何输入配置发生更改时，这两个文件最终都会被修改，因此才会包含“原始”和“补丁”文件夹。

如果您有自己的十字准线，请将其缩小到大约 64x64 像素，这样它们在屏幕上就不会太大。游戏窗口会以您的原始桌面分辨率运行，但游戏会以更低的分辨率运行（看起来像 640x480）。

无论如何，这个游戏很烂。

运行修补后的独立程序：
- 从“patched”文件夹中，将所有文件复制到“data”文件夹的根目录中，覆盖现有文件。
- 在 Game.exe 上，将兼容模式设置为 Windows XP SP3
- 运行“Game.exe”并使用以下键进行输入：

按键：
S - 服务
T - 测试模式
Q - P1 开始
E - P2 开始
C - 硬币
鼠标按钮 1 - 触发器 P1
鼠标按钮 2 - 触发器 P2
鼠标移动 - 枪 X/Y

由 Andy Geezer 模拟的补丁和 I/O 板

为什么这个游戏包含 16,259 个文件夹中的 124,817 个文件？

Linux 中的符号链接 (symlink) 是一种指向其他文件或目录的特殊文件类型，其功能类似于快捷方式。它们允许您引用文件的路径，而无需复制其内容。

在游戏原版 Linux 操作系统中，以下列出的两个文件夹位置包含许多子文件夹，每个子文件夹的内容相同。Linux 使用符号链接创建这些文件的副本并指向原始文件位置，从而节省空间。

然而，符号链接无法存在于 Windows NTFS 驱动器上（至少 Linux 基于 ext 的符号链接类型无法存在）。为了使所有这些符号链接文件能够在 Windows 平台上存在，必须将所有符号链接替换为真实文件。这就是为什么该游戏比原版 Linux 版本大约大 150MB 的原因。

\drv\nvidia\180.29\lib\X11\xserver\
\drv\nvidia\base\lib\X11\xserver\

铁拳双打锦标赛 2 (2011) (ttt2)
ROM：TG2100-1-NA-HDD0-E06

如果您的 RPCS3 转储在 SCEEXE000 文件夹的根目录中有一个 EBOOT.BIN（与 ICON0.PNG 文件一起，以供参考），则需要将其移动。  
1. 在 USRDIR 中，将 EBOOT.BIN 重命名为 EBOOT.BIN.BAD
2. 从 SCEEXE000 文件夹中，将 EBOOT.BIN 移动到 USRDIR 文件夹中
3.游戏现在可以运行了。

正确的 EBOOT.BIN CRC：3DD05100
错误的 EBOOT.BIN CRC：919F19EC

不知何故，EBOOT.BIN.BAD 文件被十六进制编辑，将 SCEEXE000 文件夹重命名为 SCEEXE001，而 TP 设置中并不存在该文件夹。我不知道为什么要这样做，可能与 RPCS3 有关，我不想再花时间去琢磨原因了。

- 可用语言：英语
