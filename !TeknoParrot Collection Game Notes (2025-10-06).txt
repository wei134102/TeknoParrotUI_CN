iDmacDrv32.dll

Some games will have older versions of iDmacDrv32.dll in their archive, which may be older than the current one that TPUI recommends using.

If you are experiencing any issues with a game that has iDmacDrv32.dll in the root folder, rename that dll file and start the game.  TPUI will automatically copy the current iDmacDrv32.dll from its repository into the game folder and use it.  If that fixes your issue, then continue to use the new iDmacDrv32.dll

D:\TeknoParrot\TeknoParrotUi.exe --profile=GoldenTeeLive2012.xml

You'll need to make sure you have all the game's settings pre-setup, including the path to the game executable.

you can get the profile names from the TeknoParrot\GameProfiles folder, or from searching for the game in this document and the profile name will be in brackets next to the game title.

============================================
NESiCAxLive game files

If you look in the root of a NESiCA game folder and see the following .dds files, leave them alone.
NxLCountDownRenderer_HD.dds		(2048x512)
NxLCountDownRenderer_HD_V.dds	(512x1024)
NxLCountDownRenderer_SD.dds		(1024x256)
NxLCountDownRenderer_SD_V.dds	(256x512)

They belong to the game and are not added on by 3rd party tools, like some users would have you believe. They are graphics tiles created for and used by the game loader to do a countdown while the game is booting. Unfortunately, that process is snubbed out by TPUI so you never actually see them.  They are in SD and HD resolutions for both portrait and landscape monitor orientation.

If these .dds files are deleted it is not the end of the world, however, if these files are missing the game will no longer load in-game bezels, if available.

Namco System 357 Games

First boot will take 2-4 minutes for RPCS3 to create the cache/shader files, which are stored in the RPCS3\cache folder.  Once they've been created once, subsequent game boots will be significantly faster.

Windows Scaling
Set your Windows Scaling to 100%, otherwise your aim will be off in crosshair games.

============================================
Fullscreen Resolutions
A few games can be affected by monitor frequencies set higher than 60Hz when trying to run them in fullscreen mode. Drop the frequency to 60Hz to fix the problem. (Star Trek, HOTD4, Golden Gun, Transformers)

============================================
BepInEx Unity games
When starting a Unity game that contains a BepInEx folder FOR THE FIRST TIME, allow the game to start, then exit and restart the game.  This will allow BepInEx to save and update its plugin configurations.  After that, the plugin will be fully configured.

Golden Tee "Score Submission" setup 

Enabling this will allow you to submit your game scores to the website leaderboard.  It also creates a video recording of your round and saves it in a folder.  It will record up to 10 videos, deleting the oldest video first to make room for new ones.

- Log into TeknoParrot.com
- Click on Online Profiles
- Click on High Scores
- Your Submission ID Serial will be displayed
- Load up TeknoParrotUI and update if necessary
- Go to Settings (NOT game settings)
- Copy Submission ID Serial from TeknoParrot.com to Score Submission ID (This is unique to each individual user, keep private!)
- Under Game Settings, Enable Score Submission and optionally you can Enable GUI now for GUI to be rendered onscreen with game info etc

3D Cosplay Mahjong (3DCosplayMahjong)

- game only natively works in windowed mode
- if you try to run it in fullscreen, you'll be met with the following errors:
Error!! : Create3DDevice
fGf%.!! : Game

The only workaround I've come across to force the game to work in fullscreen mode is to use "Borderless Gaming" (BG) from github (https://github.com/Codeusa/Borderless-Gaming/releases).  It's a safe app that you can apply to running applications that will take their window and expand it to fullscreen, in the resolution you have your monitor set to.  

I've tested BG with this game and it works great.  Download that latest non-steam version, install and run the BG app. Run TeknoParrot normally, select 3D Cosplay game, and ensure it is set to "windowed" mode.  Run the game.  When the game starts, look at the Applications list in the BG window for an application called "3DCustomMahjong [Title]".  Highlight it and click on the right arrow to move it to the Favorites (automatic) list. Now anytime you run BG and then run 3D Cosplay, BG will automatically switch the game into fullscreen.

Maybe the TP devs can fix this, but probably not since they don't give a damn about mahjong games, even with provocative ladies flirting with their goodies.

Oddly, the game seems to have two video modes, horizontal and vertical (based on the movie_h.wmv and movie_v.wmv game files).  However, checking the service menu, there is no way to make any changes to the orientation of the screen.

THIS GAME DOES NOT WORK WITH 12th-14th GEN INTEL CPU'S (not GPU.. I'm talking about the CPU).  You can set everything up perfectly, but the TRIGGERS will not work. Does not matter if you try mapping them to a controller or keyboard either.. the triggers simply will not work.  I can only personally confirm that a 13th gen Core i7 will not work, the other reports come from other users.

- on Game.exe, set compatability mode to Windows XP SP3
- run TPUI as administrator for this game (for compatability mode to work)
- setup game using RawInput, HideCursor, FpsLimitEnable (60), Crosshair Enable, Bezel Enable.
- map light gun to mouse.  
- play game.

The "expdat" and "extdat" files are the patched versions of the NVRAM which has Free Play enabled (this is how you know you're using the patches files). Trying to use the "original" versions of these two files will result in no inputs working at all, and the game will no longer be in Free Play mode.  These two files do eventually get modified when any input configurations are changed in TPUI, hence why the "original" and "patched" folders are included.

If you have your own crosshairs, scale them down to about 64x64 pixels so they're not super large on the screen.  The game window runs at your native desktop resolution, but the game runs at a resolution way lower (looks like 640x480).

This game sucks anyway.

This game is now using ddrawcompat as a fix.  The game will start with TPUI, but will get stuck on the NOTICE screen.

Once you are on the NOTICE screen, wait 10-15 seconds and you will hear a Windows exclamation sound.  Press the ENTER key on the keyboard and the game will start.  The game throws an "failed to initialize audio mixer" error in the background, and since the error window becomes the active window (but is covered up by the NOTICE screen), pressing the ENTER key selects the window's "Close" button. - language options in the service menu are English and Chinese
- native resolution 1280x768

I have changed the FRAME_COUNT to 30 as this is required for the game to play properly.  If the opponents are super-fast and lapping you, read below.

Why are the opponents way faster than me? 
- you edited the \data-hummer\config\kernel.nut file and set the FRAME_COUNT higher than 30. 
- change the FRAME_COUNT to 30. if it is set higher, the AI will not behave properly.

Why does this game contain 124,817 files in 16,259 folders?

Symbolic links (symlinks) in Linux are special types of files that point to another file or directory, functioning like a shortcut. They allow you to reference a file's path without duplicating its contents. 

In the game's original Linux-based OS, the following two folder locations listed below contain many subfolders with identical contents in each of them.  Linux uses symlinks to create copies of these files and point to an original file location, thus saving space.

However, symlinks cannot exist on Windows NTFS drives (at least not linux's ext-based flavor of symlinks). In order for all these symlinked files to exist on a Windows platform, any symbolic links had to be replaced with the real files. This is why the game is about 150MB larger than the original Linux version.

\drv\nvidia\180.29\lib\X11\xserver\
\drv\nvidia\base\lib\X11\xserver\

Super Monkey Ball Ticket Blitz (Mballblitz)

- This game is for trackballs only. 
- You can use a mouse to get the monkey to start moving, but you won't gain any real speed and end up stuck in various places that have any sort of incline.
- The game chooses one of twelve random levels to start.  You only get to play one level per game.

- This game records revealing digital information when it creates text files used to store a player's game stats.  
	1. It queries for the hostname of the computer the game is running on
	2. It queries for the current logged on user's local username
	
	The game then creates game stat and replay files based on the hostname, username, and stage number in the following format, for example:
		averageinfo_MyComputerName_MyLocalUserName_stage0xx.txt
		playinfo_MyComputerName_MyLocalUserName_stage0xx.txt
		replay_MyComputerName_MyLocalUserName_20250518_130802.rep  (this filename also records the date and time)

	The game will start writing these files into one of the "playrecord\stage0xx" folders as each level gets played.

	If you're a privacy advocate, you will want to ensure you delete these files after playing the game on your own PC before sharing the game files to someone else.

- The "prjMonkey_tv_final.exe" game file is patched to run in 1920x1080.

- The game's native resolution is 1280x720.  The closest patch is 1280x768.

- There are additional patched executables available which will force the game window to run in a specific resolution - these executables work fine in TP. Standard 4:3 resolutions will not look correct and the right side of the screen will get cut off, as the game is natively widescreen. Use a widescreen resolution for best results.  I have placed these patched exe's in the "various patched resolutions" folder.  Simply rename the existing exe and copy the executable you want to use into the main game folder.

- If you have multiple monitors and select a patched resolution larger than your main monitor supports, the game will spread the game screen out over multiple monitors.

- The game's service mode save files are located here:
%USERPROFILE%\AppData\Roaming\TeknoParrot
SBVJ_sram.bin
SBVJ_e2prom.bin

- Use the "test mode" toggle in TPUI to enable running test mode if you want to change things like difficulty, ticket/amusement mode, and game time.
- The game volume is set quite low, and there is no volume adjustment via the service menu. You'll need to crank up your speakers instead.

Running the game without TP:

- Running "Play.exe" directly from the game folder will run the game in fullscreen (non-windowed) mode. Keyboard commands are:
	Esc or F11 = exit game
	0  or  F10 = insert coin
	1 or F9 = start coin 
	PageUp / PageDown = volume +/-
	You still need to use a trackball though, you won't get anywhere with a mouse.
	
- Someone also setup XPadder as a standalone patch to work with "Play.exe", so you can play the game with your gamepad as TP does not currently support movement on gamepads at this time. 
 - Install AutoHotKey
 - run XPadder.exe once and add the file association (.xpadderprofile).  You can do this either during the XPadder setup, or in the settings (main window, wrench icon in top right, select Installation, and click on Associate files) 
 - run "Run_Super_Monkey_Ball_Ticket_Blitz.ahk"
 - game will only run with its default settings and set for ticket redemption (meaning you'll likely never get a jackpot)
 
It's better to just do it manually,
 - run XPadder.exe
 - to the left of the word "XpadderProfile" is a button that looks like a document. Click on that and select "Open"
 - open the file "XpadderProfile.xpadderprofile"
 - leaving XPadder running, run Play.exe and you'll now be able to control the monkey with your gamepad.  Press ESC to exit the game, and close the XPadder window. 
 - in Settings > Options, if you enable "AutoOpen last used profile", it will reopen the profile when you run it so you don't have to do it repeatedly.

Namco System 246 common notes:

If using MAME CHD's as the disc source, you will need to ensure the CHD is in the correct format. Download the latest MAME binary release from https://www.mamedev.org . Extract chdman.exe and use it to check the CHD's using Command Prompt.  Substitute "image" for whatever the CHD is called.

Add chdman.exe to your system path, or copy the exe into the folder next to the CHD. Run the following command:
chdman.exe info -i image.chd

If you see:
 Metadata: Tag='GDDD'
it means your CDVD image needs to be converted. 

It can be done in 3 steps (substitute the word "image" for the name of your CHD):

rename or copy "image.chd" to "image.chd.orig"
chdman.exe extracthd -i image.chd.orig -o image.iso
chdman.exe createcd -i image.iso -o image.chd

when you have your converted CHD, you can delete "image.iso" and do whatever you want with the old "image.chd.orig"

Some GDDD drive images are huge, I've seen them into the hundreds of GB.

[region_1]
self=GAME0180.SELF karmalimit=1000 karmadec=1 romver=H05 muchagidno=1 muchaappver=0205 pairplay=1 keylatency=1 offline
--------------------------------------------------------

- inside the download is "chdman.exe", copy that to a temp folder that also contains offrthnd.chd
- start a command prompt window, change the path to the temp folder and type:
	chdman extracthd -i offrthnd.chd -o offroad.img
- when complete, right-click on "offroad.img" and in the context menu, select 7-Zip and "Extract to offroad\"
- after that img is extracted, go into the "offroad" folder

- take the file contents of both "0" and "1" folders and combine them together into a single folder called whatever you want
- take that folder and put it with your other TP games.. you've got the game files now.
- delete any leftover files, you don't need them.

If you just extracted the game yourself from the CHD, you will need to patch your game exe:
- get "ThunderPatcher&ThunderGlide2x" fix patch from the TP Discord server
- put Glide2x.dll and ThunderPatcher.exe in the game folder
- drag and drop the "offroad3.exe" game file on to ThunderPatcher.exe. It'll create 2 new executables, offroad-x86.exe and offroad-x64.exe.
- delete ThunderPatcher.exe from your game folder.
